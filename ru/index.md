# Sticker.fit

Приложение для Android, чтобы создавать стикеры, собирать их в наборы и устанавливать в WhatsApp, с
публичным каталогом материалов, которыми делятся его пользователи.

Этот сайт — не приложение: здесь живут документы, которые должны читаться без его установки и
исправляться без выпуска новой версии.
