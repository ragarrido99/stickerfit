# Sticker.fit

Une application Android pour créer des stickers, les réunir en packs et les installer dans WhatsApp,
avec un catalogue public de contenus partagés par ses utilisateurs.

Ce site n’est pas l’application : c’est là que vivent les documents qui doivent pouvoir se lire sans
l’installer et se corriger sans publier une nouvelle version.
