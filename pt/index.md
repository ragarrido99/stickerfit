# Sticker.fit

Um aplicativo Android para criar figurinhas, juntá-las em pacotes e instalá-las no WhatsApp, com um
catálogo público de conteúdo compartilhado por seus usuários.

Este site não é o aplicativo: é onde ficam os documentos que precisam poder ser lidos sem instalá-lo e
corrigidos sem publicar uma versão nova.
